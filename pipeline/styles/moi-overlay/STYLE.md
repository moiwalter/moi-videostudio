# Moi Overlay

This is the existing Moi HTML/KIT style. Its continuous overlay coverage, caption-lane rules and CapCut alpha handling apply to this selected style. They are not universal rules for every client or Paper Collage.

Use native preview and the shared scene metadata. Approve the actual scene revision, render transparent clips as premultiplied ProRes 4444 when needed, and validate the complete final KIT. Reuse client brand tokens rather than literal colors copied from another episode.
