# templates/takeovers — reusable takeovers, any brand, 16:9 and 9:16

Two files, inlined into each scene `<template>` (HyperFrames drops styles outside it):

| file | what |
|---|---|
| `takeovers.css` | components. Colours ONLY `var(--role)` from `brand.mjs tokens <marca>`; sizes ONLY container units. |
| `transitions.js` | `window.TK` — cut/takeover motion on a GSAP timeline (API in the file header). |

## Scene skeleton

```html
<template>
  <style>/* brand.mjs tokens qmd */ /* takeovers.css */ #s1 .extra{…}</style>
  <div id="s1" data-composition-id="s1" data-width="W" data-height="H">   <!-- root: NO class -->
    <div class="tk-stage">                      <!-- size container: cq units + safe areas -->
      <div class="tk-ground mode-light"></div>  <!-- ground of the look -->
      <div class="mode-light" style="position:absolute;inset:0"> … components … </div>
    </div>
  </div>
  <script>/* transitions.js */ (function(){ var tl=gsap.timeline({paused:true});
    TK.tkIn(tl,"#s1-card",0.2); … window.__timelines["s1"]=tl; })();</script>
</template>
```

* **Do not put `tk-stage` on the composition root** — HyperFrames lint `subcomposition_root_styled_by_class`.
* **Looks**: wrap in `.mode-<name>` from the brand's `modes`. QMD = `.mode-light` (paper, default) and
  `.mode-green` (full green when the answer lands / end card), changed with `TK.flood` on a
  `.tk-flood.mode-green` layer. The dark explainer look is **retired** (off-brand) and `brand.mjs check`
  fails any `.mode-dark`.
* **Orientation**: one markup; `@container (aspect-ratio < 1){…}` for 9:16 tweaks. Never two copies.
* **Safe areas**: `--safe-t/b/l/r`. 16:9 = 5/6/5/5 %; 9:16 = 11/34/7/12 % (bottom includes the caption
  band at 66–76 % and platform UI, right = action rail). Override per scene if needed.
* **Type floor**: ≥ 2.7cqmin (≈29 px on a 1080 short side; HF craft floor is 28 px).
* GSAP can't tween `var()`/cq strings inside `clipPath`/`y` — use `yPercent`, percentages, or CSS vars
  as tween targets (`"--hl-p"`, `"--cut"`).

## Components

`.tk` (centred takeover box) · `.tk-kicker` / `.tk-source` (mono labels; source like `[reported] …`) ·
`.tk-doc` + `.tk-doc-head/.tk-doc-dot/.tk-msg/.tk-avatar` (+`.is-dead`) document/thread card ·
`.tk-hl` highlighter (`TK.hl`) · `.tk-number .n` · `.tk-tag` price/label tag (`TK.drop`) ·
`.tk-title` (+`em` in accent) · `.tk-chain` + `.tk-layer` (`<b>name</b><small>note</small>`) with solid
tonal fills `.c-l1 … .c-l4` (brand roles `layer-N` / `layer-N-ink`; QMD: darkest green → green → lime → sand) ·
flow colours `.c-data .c-money .c-risk` (roles `flow-data`, `flow-money`, `risk`) ·
`.tk-flow(.down)` + `.tk-flow-label` · `.tk-flood` · `.tk-end`.

Worked example (both orientations, paper → green): the goldmine v3.3 master, generated by `pipeline/templates/qmd-vertical/build.mjs`.

## Added for the industry explainer (Oct 31 2026)
- Contrast: `.tk-kicker` and `.tk-source` are full ink/accent at 2.8cqmin and weight 500 (no grey, no opacity), so `[reported]`-style labels read at phone size.
- `.tk-stamp`: outlined mono stamp (INFERENCE, FEELS FAKE, SHUT DOWN). `--c` sets the colour (defaults to `--negative`).
- `.tk-bars` / `.tk-bar` (`.lbl`, `.track`, `.fill` sized by `--v` 0..1 and grown with scaleX, `.val`): bars on one scale. Single column on 9:16.
- `.tk-cards` / `.tk-card` (`small` tag, `b` claim, `span` detail): 2×2 on 16:9, one column on 9:16.
- `.tk-head`: a title pinned to the top of the safe area, for bars, cards and ladders.
